# tfb-pdf

cPanel shared hosting üzerinde çalışabilen, açık kaynaklı, Türkçe/İngilizce PDF yönetim ve düzenleme platformu.

Self-hosted, open-source PDF management and editing platform (Turkish/English) designed to run on standard cPanel shared hosting.

> **Durum / Status:** Geliştirme aşamasında. Henüz kullanıma hazır değil. İlerleme: [docs/PROGRESS.md](docs/PROGRESS.md)

Stack: PHP 8.2+ · Composer · MySQL/MariaDB · Bootstrap 5 · Vanilla JS · PDF.js
